# @preplai/illustrations

88+ programmatic SVG component types organized into families (infrastructure, data structures, algorithms, architecture, networking, diagrams).

Every illustration is a pure function `(props) → SVG string` — no static files, fully parameterized.

> This package is part of the preplai ecosystem but is not actively used in v1. SVG rendering is currently handled by the player's inline JavaScript. This package will be integrated in a future release.

## Status

Future work — not used in v1 shipping build.
