# @preplai/compiler

5-stage compilation pipeline that transforms high-level visual scripts into render-ready frames.

Stages: Validate → Defaults → Positions → Connections → Temporal

> This package is part of the preplai ecosystem but is not actively used in v1. The compilation logic is currently handled inline by the mcp-server. This package will be integrated in a future release.

## Status

Future work — not used in v1 shipping build.
