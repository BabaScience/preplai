## Product Positioning (from designer review)
- MCP for creating presentations instead of long text
- Saves personal tokens using the user's Claude
- Solves AI agent traceability — many don't know what agents do each day
- Target: engineers who use AI for code but lose the big picture
- Use cases: daily summaries, code change analysis, visual study

## Landing Page Structure (SaaS best practice)
1. Clear value proposition at the top
2. Highlight the problem you solve
3. Specific features
4. Case studies / usage examples
- Reference: Whisperflow as example of effective storytelling
- Priority: clarity and accessibility over visual design initially

## Language & Messaging
- Avoid overly technical language — people leave
- "MCP" is still too complex for many (especially designers)
- Use the language of the people who will use it
- Keep it simple and accessible

## User Testing Strategy
- 10 well-done interviews reveal recurring problems
- Don't suggest how to do things during tests
- Give specific tasks and observe behavior
- Have users narrate their mental process
- Record and take detailed notes
