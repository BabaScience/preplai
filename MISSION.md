# Preplai Mission

> **"The agent understands. The engine shows. The user learns."**

Preplai is a **cinema-quality visual presentation engine** exposed as an agent-native API. AI agents create live, animated, voice-synced visual experiences — not slides, cinema.

## Core Principles

1. **Code over content** — Illustrations are programmatic SVG components, not static files. Every type = one render function.
2. **Agent as director** — The agent emits structured JSON; the engine renders it. No design tools, no asset libraries.
3. **Cinema-grade output** — Best-in-class interface for agent→human visual communication.
